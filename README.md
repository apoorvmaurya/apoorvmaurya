## 🚀 Featured Projects

### [RetentIQ](https://github.com/apoorvmaurya/retentiq) - Customer churn-intelligence and health-scoring platform
Scores customer churn risk with **LightGBM**, explains every score with **TreeSHAP**, and generates per-account retention playbooks with an LLM.

- **Stack:** Next.js 16 · FastAPI · Supabase · LightGBM · SHAP · Docker · CI
- **Try it:** [**Live demo (1-click guest sandbox, no signup)**](https://retentiq-chi.vercel.app/login?guest=true)

### [Planora](https://github.com/apoorvmaurya/planora) - Group trip planning that actually ends in a plan
Turns group indecision into a finished itinerary: AI-generated plans, real-time group voting, and shared expense tracking.

- **Stack:** Next.js · GPT-OSS with Llama as Prompt Guard · Supabase Realtime
- **Try it:** [**Live demo**](https://planora-plum-beta.vercel.app/)

### [AssesMed](https://github.com/apoorvmaurya/AssesMed) - Clinical risk assessment for non-technical users
A guided, multi-step, fully validated intake form with data visualization, designed to be easy for people with no technical background.

- **Try it:** [**Live demo**](https://assesmed.vercel.app/)

### [Deal-Analyzer-V3](https://github.com/apoorvmaurya/Deal-Analyzer-V3) - Contract intelligence with multi-agent review
RAG over contracts with **hybrid retrieval** (dense embeddings + BM25), plus a multi-agent layer where **legal, financial, and compliance agents are arbitrated by a judge agent**.

- **Stack:** Python · Qdrant · BM25 · Streamlit · Docker
